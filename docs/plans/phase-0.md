# Phase 0: audit, restructure, fix

## Audit (2026-11-12)

Known problems from CLAUDE.md section 3, all confirmed in the code, plus:

- **Secret in git:** `.env` (Twelve Data key) was committed in the initial commit and pushed to GitHub.
- **Lookahead (confirmed):** `merge_asof` on candle open time gave each 15m row the close of the still-open 1h
  candle. The live path also used the forming higher-TF candle.
- **Train/serve skew:** training computed EMAs on 61-candle windows, live on 100 candles (EMA values depend on
  the window), and live inference silently filled missing features with 0.
- **Timezone:** Twelve Data timestamps were parsed as machine-local time (PKT here), shifting every candle.
- **Labels:** flat outcomes were labelled "down".
- **backtest.py:** strategy returns used the previous candle's move (misaligned); fees charged every candle.
- **evaluate.py:** broken for forex (did not map `/` to `_` in the model filename).
- **app.py (Streamlit):** drew a random price chart labelled as live price movement and showed raw confidence as
  "Recommended action". It breaks the honesty rule, so it was removed (recoverable from git `47ea0642`).
- **knowledge_base/test_*.py:** manual network scripts, not tests (moved to `backend/scripts/`).
- **Reuters RSS feed:** discontinued; the news layer needs a new source (Phase 3).
- **Data terms:** the Twelve Data free plan is "internal non-display usage only" (see `docs/DATA_SOURCES.md`).

## Defaults chosen (override if needed)

1. Work on local branch `phase-0`; nothing is pushed.
2. Old `.pkl` models deleted (trained with the leaked feature). New artifacts are XGBoost JSON + metadata JSON shaped
   like `model_versions`, gitignored, rebuilt by the pipeline (about 0.43 MB per model).
3. **Label changed** (reversible: `label_mode` in `ml/config/models.yaml`). Entry = open of candle t+1 (first
   tradeable price after the signal), exit = open of candle t+h+1; up = exit > entry. Reason: in the Twelve Data
   forex/gold feed, open and close behave like different sides of the bid/ask spread. Opens sit below the
   previous close, and bodies are up 54-61% of the time (Binance: 50%). Close-to-close labels therefore carry
   spread noise that a trivial "reverse the last body" rule predicts at 54-62%; under that label XAU/USD 15m
   looked like 63% with every signal "Strong". Mixing open and close (first attempt) builds in a fake up-drift.
   Open-to-open cancels the constant offset. 1m forex stays contaminated under every label (spread is large
   vs 1-minute moves). The report shows per-model feed checks. Phase 2 outcome resolution must use the same
   definition. Flat outcomes are excluded; their rate is reported.
   - **Market hours:** about 25% of Twelve Data forex/gold candles fall while the market is closed
     (New York Fri 17:00 to Sun 17:00). They have tiny ranges, many flats and most of the open/close skew, so
     they are dropped in training and live inference (same filter, `ml/data/sessions.py`). On trading-hours
     candles, 15m labels are ~50/50 and trivially predictable at only ~50.5%.
   - **1m forex/gold:** the next open lands on the opposite side of the close 97-99% of the time even in
     trading hours (synthetic candle construction). No label fixes that, so these models are gated off.
   - **Usability gate:** a model serves strength tiers only if its 95% OOS interval clears both the majority
     and naive baselines and the naive rule scores < 55%. Otherwise every signal is "Very Weak - Wait".
4. Platt calibration by default (isotonic available); headline metrics use blocks 2+, tier metrics blocks 3+.
5. Strength tier levels (95% lower bound, Bonferroni over a 0.50-0.80 grid, min 100 signals): Strong 60%,
   Good 56%, Moderate 53%, Weak > 50%; otherwise "Very Weak - Wait".
6. Model hyperparameters unchanged from the old `train.py` (no tuning in Phase 0).
7. History: 3 months for 1m, 12 for 5m/15m, 24 for 1h. Same model set as the old registry, including BTCUSDT
   (research only).
8. The report adds a naive "repeat/reverse last candle" baseline, because short-timeframe quotes mean-revert slightly.
9. `prev1_*` now means the previous candle (old code: three candles back). The pattern zero-range floor is now scale-free.
10. Inference uses 500 closed candles (training drops the first 500 rows) so EMA warm-up matches.
