# Zentrix

Trading assistant for forex and gold traders: a direction signal with calibrated confidence, an explanation,
and risk tools. **Not financial advice.** Project brief and phases: [CLAUDE.md](CLAUDE.md).

```
backend/   FastAPI app (app/), ML package (ml/), knowledge base (knowledge/), tests/, scripts/
infra/     Dockerfile, docker-compose (api, postgres, redis)
docs/      ML_REPORT.md (generated), DATA_SOURCES.md, plans/
mobile/    Flutter app (Phase 5)
```

## Backend quick start (Python 3.12)

```bash
cd backend
python -m venv .venv && .venv/Scripts/activate      # or source .venv/bin/activate
pip install -e ".[dev,news,llm]"                    # add ,knowledge for the RAG retriever (pulls torch)
cp .env.example .env                                # fill in keys; never commit .env
python -m pytest                                    # unit tests (offline)
python -m ml.training.pipeline                      # fetch data, walk-forward, train, write docs/ML_REPORT.md
python -m scripts.check_signal EUR/USD 15m          # signal for the last closed candle
uvicorn app.main:app --reload                       # GET /health
```

Accuracy numbers come only from `docs/ML_REPORT.md` (out-of-sample, generated by script) and, later, from the live
track record in the database. Never hardcode or market an accuracy figure.
