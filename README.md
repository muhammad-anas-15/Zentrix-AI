# Zentrix

Trading analysis and risk tools for FX, metals, commodities and crypto: a direction signal with calibrated
confidence, an explanation, and tools that help traders lose less. **Not financial advice.**
Project brief and phases: [CLAUDE.md](CLAUDE.md). Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
API: [docs/API.md](docs/API.md).

```
backend/   FastAPI app (app/), Alembic migrations, ML package (ml/), knowledge base (knowledge/), tests/, scripts/
infra/     Dockerfile, docker-compose (migrate, api, postgres, redis)
docs/      ARCHITECTURE.md, API.md + openapi.json, ML_REPORT.md (generated), DATA_SOURCES.md, plans/
mobile/    Flutter app (Phase 5)
```

## Backend quick start (Python 3.12)

```bash
cd backend
python -m venv .venv && .venv/Scripts/activate      # or source .venv/bin/activate
pip install -e ".[dev,llm]"                         # add ,knowledge for the RAG retriever (pulls torch)
cp .env.example .env                                # fill in keys; never commit .env
python -m pytest                                    # all tests; API tests start their own PostgreSQL
```

Run the API locally without Docker (bundled PostgreSQL 16 via `pgserver`; Redis optional, rate limiting fails
open without it):

```bash
python -m scripts.dev_db                            # prints DATABASE_URL=...; put it in .env
alembic upgrade head
uvicorn app.main:app --reload                       # http://127.0.0.1:8000/docs
```

Live signals (worker): register the trained models, then run the worker next to the API.

```bash
python -m app.workers.register_models               # ml/artifacts -> model_versions (+ ingestion targets)
python -m app.workers.main                          # candles, signals, outcomes, calendar, alerts, push
```

Push notifications need a Firebase service-account JSON (`FCM_CREDENTIALS_FILE`); without it alerts still
reach the in-app inbox (`/v1/alerts/events`).

With Docker: `docker compose -f infra/docker-compose.yml up --build` (migrations, API, worker, Postgres, Redis).

ML: `python -m ml.training.pipeline` (walk-forward, train, write docs/ML_REPORT.md);
`python -m scripts.check_signal EUR/USD 15m` (signal for the last closed candle).

Accuracy numbers come only from `docs/ML_REPORT.md` (out-of-sample, generated by script) and, later, from the live
track record in the database. Never hardcode or market an accuracy figure.
